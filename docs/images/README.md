# README hero banner

`tapin-banner.png` is the shared hero for the Persian and English README files.

- Created on **2026-10-07** with the built-in **ImageGen** tool.
- Output: **2172 × 724 PNG**, 3:1 landscape.
- Direction: midnight navy, teal routes, amber location pins and a sculptural Iran-inspired map.
- Brand input: the repository's [Tapin logo](../../assets/brand/tapin.png), sourced from the [official website logo](https://www.tapin.ir/wp-content/themes/tapin/image/logo.png). The original source asset in `assets/brand/` is unchanged.
- The logo in the generated composition was guided by that official reference, with a second pass correcting its emblem colors.
- The geography, pins and connecting lines are a conceptual illustration, not an authoritative boundary, current branch dataset, or service-coverage claim.
- Tapin's name and brand mark remain the property of Tapin.

The image replaces the former SVG concept banner. Application screenshots and live-site recordings remain documented in [media notes](../media/README.md).
