# Routing service logos

The following files are unmodified images downloaded from each service's official site on 2026-10-06. They identify the routing choices in the branch-details dialog; the service names remain visible and accessible beside the decorative logos.

| Local file | Official source |
| --- | --- |
| `routing-neshan.png` | https://neshan.org/maps/icon-256x256.png (linked by the official web app manifest) |
| `routing-google-maps.png` | https://www.gstatic.com/marketing-cms/assets/images/81/e4/1bdb808b40a28cc70ac24bf5e6fa/google-maps-favicon.png=s180 (linked by https://www.google.com/maps/about/) |
| `routing-balad.png` | https://balad.ir/favicons/favicon-192.png (linked by https://balad.ir/) |

These brand assets remain the property of their respective owners. They are bundled locally to avoid third-party image requests when opening branch details.

All three choices use a common 28 px icon frame. Neshan's image has transparent inset padding, so its image canvas is displayed at 40 px inside that frame to keep the visible brand mark comparable in size.
